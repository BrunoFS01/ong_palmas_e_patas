# 🐾 ONG Palmas e Patas — Website Institucional

Este repositório contém o código-fonte do website institucional da ONG fictícia **Palmas e Patas**, dedicada à causa da proteção e adoção animal. O projeto é focado na aplicação de boas práticas de HTML5 semântico, acessibilidade e estruturação web.

## 🛠️ Tecnologias Utilizadas

## 📁 Estrutura Atual do Site
* `index.html` — Página inicial com apresentação da ONG e missão.
* `projetos.html` — Listagem de ações, campanhas e projetos de resgate.
* `cadastro.html` — Formulário de cadastro para novos voluntários e doadores.
